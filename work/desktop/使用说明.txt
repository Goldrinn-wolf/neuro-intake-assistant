临床拾问 · 神内问诊助手（桌面预览版 0.9）

使用：完整解压文件夹后，双击“神内问诊助手.exe”。不要仅拷走 exe。
Windows 10/11 使用系统的 WebView2；旧系统目标为 Windows 7 SP1 / 8 / 8.1。
程序为 AnyCPU，32 位系统和 64 位系统会自动选择对应组件。
.NET Framework 最低 4.6.2（也可使用 4.8；Win7 必须先装 SP1）。
完整包“环境安装”内附微软 .NET Framework 4.6.2 离线安装程序；仅在系统缺少此组件时由你手动安装。
微软 .NET 官方下载：https://dotnet.microsoft.com/download/dotnet-framework/net462

接诊：顶部“新建接诊” → 选择主要症状 → 选择表现/通用问诊 → 问诊 → 查体 → 病历预览。
点选和文字输入自动保存在本机，不需要另点保存。
查体只写入已记录的所见，未查、未记录不会被自动写成正常。
操作提示和原因说明默认收起，点击小入口展开。
琥珀色表示病史提示需要关注的查体项目。

复制：顶部“复制现病史”“复制查体”“复制整份病历”始终可用。
先核对生成稿，再切换到医院系统的对应字段，按 Ctrl+V 粘贴。
现病史/查体单独复制不带标题；整份病历包含分段标题。
Ctrl+Shift+C：复制现病史；Ctrl+Shift+E：复制查体；Ctrl+Shift+A：复制整份病历。
Ctrl+N：新建接诊。工具菜单还可备份/恢复、贴边填写、置顶和复制异常体征。
手工修改预览稿后自动保存；原问诊或查体变化后采用最新生成稿，旧手改稿可展开查看。

数据：%LOCALAPPDATA%\NeuroIntakeDesktop\Profile
升级程序文件夹后，接诊数据仍保留在上述目录。换电脑请用“工具 → 备份/恢复”。
浏览器网页预览与桌面应用各有独立存储；可通过备份文件转移记录。
软件在本机组织记录，不自动登录或提交医院系统。

Windows 7：必须使用 WebView2 Runtime 109；高于 109 的运行时无法在 Win7 上启动。
兼容 SDK 固定为微软 1.0.1518.46。若附带 runtime109/x86、runtime109/x64 文件夹，程序在旧系统自动使用它们。
现代系统优先使用已安装的新版 WebView2，缺失时使用随包运行时。
若使用轻量包而未安装 WebView2，请先从微软官方部署运行环境：
https://developer.microsoft.com/microsoft-edge/webview2/
旧运行环境已停止更新；兼容目标不等于已完成 Win7 实机验证。
本次已在当前电脑实测 WebView2 109.0.1518.140 与新版内核下的启动、生成、复制。
完整包 Runtime 109 文件来自微软更新目录，原始包与 msedgewebview2.exe 的微软签名均验证有效。

演示病例均为虚构。临床使用前核对生成文字和实际所见。
